# Xonotic Community Tournaments website

This is the source code behind **[duelmasters.gamer.gd](https://duelmasters.gamer.gd)** — a free, community-run tournament website built by fans, for fans.

We publish our code openly so the community can see exactly how the platform works, report issues, and contribute improvements. No secrets, no black boxes.

---

## 🌐 Want to join or create tournaments? Head to the site

👉 **[duelmasters.gamer.gd](https://duelmasters.gamer.gd)**

This repo is just the code. To join/create tournaments, create an account, or hang out — go to the website.

## 🤝 Want to contribute?

You don't have to be a developer to help. You can:

- 🐛 **Report bugs** — something broke? Tell us
- 💡 **Suggest features** — open an issue with your idea
- 🧑‍💻 **Submit a PR** — if you can code, fixes and improvements are welcome

Keep changes focused. Don't try to make it commercial or corporate — this is and always will be a free fan project.

---

## Tech Stack

Backend: PHP & MySQL (Robust, server-side logic)

Real-time: Workerman WebSockets (Live match updates)

Frontend: Vanilla JavaScript (Fast, framework-less UI)

Philosophy: Zero dependencies for maximum transparency
